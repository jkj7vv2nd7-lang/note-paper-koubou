# ノート用紙工房 ― 操作マニュアル

授業で使うノート用紙を、設定に合わせて作って実寸で印刷できるWebアプリです。

## 使い方
1. 左のパネルで「用紙の種類」を選びます（12種類）。
2. 用紙サイズ（A4/B5/A3）・向き・余白・線の色などを決めます。
3. 「印刷する（実寸）」ボタンを押します。印刷画面で倍率100%（実際のサイズ）を選んでください。PDFに保存する場合もこの画面からできます。

## 用紙の種類
- 方眼紙：マス1/2/5/10mm、太線の間隔も指定できます
- 座標グラフ：X/Yの範囲、目盛りの間隔と分割、数値の表示/非表示、軸の名前、第1象限のみボタン
- 罫線ノート：6〜10mm（A罫・B罫相当）、左の縦線（マージン）のON/OFF
- 漢字マス目：十字リーダー入りのマス（12/15/18/20mm）
- 原稿用紙：400字（20×20）/ 200字（10×20）、中央に折り目線
- 英語4本線：高さ12/15/18mm、ベースラインは赤色で強調
- 五線紙：線の間隔・段の間隔・段数（自動あり）
- 対数グラフ：片対数（Yが対数）/ 両対数、桁数の指定（高校理科向け）
- 極座標：円の間隔と放射線の角度
- アイソメトリック：三角方眼（1辺の長さ指定）
- ドット方眼：5/10mm間隔
- 無地（枠のみ）：自由なワークシートの下地に

## 共通機能
- タイトル欄、名前・日付・クラス欄、指示文欄のON/OFF
- 全面 / 半ページ×2 の配置
- 5cmチェック線：左上に印刷される赤い線で、実寸どおり印刷できたか確認できます
- プリセット：小学校・算数、中学校・数学、国語（漢字・原稿用紙）、英語、高校理科、音楽の6様式
- マイ様式：よく使う設定に名前を付けて保存・呼び出し（端末内に保存）
- 前回の設定は自動で覚えています

## 関数グラフの自動描画（座標グラフ）
式を入力すると曲線を自動で描きます。複数本を色分けして重ね描きでき、各式の表示/非表示と削除もできます。描いたグラフは印刷・図の書き出し・黒板モードにもそのまま反映されます。
- 入力例：x^2、2x+1、sin(x)、sqrt(x)、abs(x-2)、log(x)、1/x
- 使えるもの：x、数、+ − × ÷、^（累乗）、かっこ、sin cos tan、sqrt、abs、log（常用対数）、ln（自然対数）、exp、pi、e。「2x」のような掛け算の省略もできます

## 点と図形（座標グラフ・方眼紙）
座標を指定して点を打ち、ラベル（A、B、C…の自動採番、または任意名）を付けられます。点を2つ選んで直線、点を中心に円（半径指定）、3点で三角形も配置できます。「目盛りに吸着」をONにすると、座標が目盛りやマスの半分に吸着します。方眼紙ではマス目単位（原点は左下）です。配置した図形は印刷・書き出しにも反映されます。

## 黒板モードの黒板テーマとタイマー
- 黒板テーマ：ツールバーの「黒板テーマ」ボタンで、用紙が深緑の黒板色になり、線と文字がチョーク風の淡い色に切り替わります。ペンの色にはチョーク色（白・黄・ピンク・空色）が追加され、ペンは自動で白に切り替わります
- タイマー：分数を設定して「タイマー開始」を押すとカウントダウンします。終了すると表示が点滅し、音でも知らせます（演習の時間管理に）

## 設定の共有（JSON）
パネルの「設定をJSONで書き出す」で、現在の設定（様式・関数・図形を含む）をファイルに保存できます。「JSONを読み込む」で別の端末やブラウザでも同じ設定を再現できます。

## 黒板モード（電子黒板として使う）
パネルの「黒板モード」ボタンを押すと、用紙が画面いっぱいに大きく表示され、その上に手書きできます。教室のモニターやプロジェクターに映しての授業にどうぞ。
- ツールバーは数秒操作しないと自動で隠れ、用紙と書き込みだけが画面に残ります。画面の上端にマウスを近づける（タップする）と再び現れます
- 終了ボタン（右上の ✕）とタイマー表示（右下）は、控えめな半透明で隅に残ります
- ペン：色（黒・赤・青・緑）が選べます。Apple Pencil・指・マウスに対応
- ペンの種類：「ペン」（通常）と「マーカー」（半透明の蛍光ペン風で、下の文字や線が透けます）
- 太さ：スライダーで細かく調整できます（1〜14）
- 線の種類：実線／破線／点線（補助線や漸近線などに）
- 消しゴム、1画戻す、全消し
- 「書き込みごと保存」：用紙と書き込みを合成した画像（PNG、300dpi）を保存できます
- 終了ボタンで通常の画面に戻ります。書き込みはアプリを開いている間は保持され、黒板モードを開き直すと続きから使えます
- 黒板モード中は画面のスクロールやピンチ操作が書き込みと競合しないようになっています

## 図として書き出す（Word・テスト作り向け）
パネルの「図として書き出す」から、生成した図をファイルや画像にできます。
- SVGで保存：ベクター形式。Wordに貼っても拡大縮小で崩れず、用紙の実寸（mm）で貼り付きます
- PNGで保存：150/200/300dpiから選べる高解像度画像
- 画像コピー：クリップボードに画像をコピーし、Wordへそのまま貼り付けできます（環境によっては使えない場合があり、そのときはPNG保存をご利用ください）
- 書き出す範囲：「用紙全体」か「描画エリアのみ」（名前欄やタイトルを除いた図の部分だけ）。座標グラフでは、グラフ部分だけを切り出せます
- 貼り付け幅（cm）：描画エリアのみの場合に、Wordへ貼る幅を指定できます。高さは比率を保って自動で決まります

## 印刷の注意
- プリンターの設定で「実際のサイズ」「100%」を選んでください（「用紙に合わせる」は実寸がずれる原因になります）
- 印刷後、5cmチェック線を定規で測ると、実寸どおりか確かめられます

## 出典・ライセンスについて
このアプリは、海外のグラフ用紙作成サイトの「設定項目の考え方」を参考に、日本の学校向けに独自に設計・実装したオリジナルです。用紙の様式そのもの（方眼・罫線・原稿用紙など）は一般的な文具の形式です。
